\# Student Performance Prediction System



\## Project Overview



The Student Performance Prediction System is a Python-based machine learning project designed to analyze student-related data and predict academic performance. It demonstrates how data preprocessing, exploratory data analysis, and machine learning techniques can be used to understand student performance.



This project was developed as part of a group academic project, with my primary contribution to development.



\## Features



\- Process and preprocess student datasets.

\- Analyze student data and performance patterns.

\- Train and evaluate machine learning models.

\- Predict student performance using the implemented model.

\- Generate analysis results and model outputs.

\- Organize datasets, models, and results into separate folders.

\## Getting Started



\### 1. Install Python



Install Python 3.10 or a compatible version.



\### 2. Open the project folder



Open Command Prompt inside the project directory.



\### 3. Create a virtual environment



```bash

python -m venv venv

```



\### 4. Activate the environment on Windows



```bat

venv\\Scripts\\activate

```



\### 5. Install dependencies



```bash

pip install -r requirements.txt

```



\### 6. Run the application



```bash

python -m streamlit run app.py

```



If the application uses Streamlit, open the local URL displayed in the terminal.
